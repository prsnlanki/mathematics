# Mathematics

My mathematics Anki deck, `Mathematics` in Anki. It starts with one subdeck, **Multiplication**: the tables 2–20 × 2–20, as typed and timed product (7 × 8) and division (56 ÷ 7) cards plus self-graded factoring cards (36 → 2×18, 3×12, 4×9, 6×6), so the answers come instantly.
